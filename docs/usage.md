# Subjector MVP 간단 사용법

이 문서는 현재 테스트된 Subjector MVP 기능을 기준으로 한다.

## 기본 채널

- `#회의-결과록`: 회의 녹음 업로드, 회의 전사, Speaker A/B/C 매핑, 회의 기반 task 생성 흐름
- `#in-process`: 개인별 진행 중 task 보드
- `#finals`: 프로젝트 누적 결과 정리
- Subjector Bot DM: 출근, 최신화, 퇴근, finals 업데이트, 회의 후 개인 의견 입력

## 회의 녹음에서 task 만들기

1. `#회의-결과록`에 회의 녹음 파일을 업로드한다.
2. Subjector가 업로드를 기록하고 전사를 시작한다.
3. 전사가 완료되면 스레드에 Speaker A/B/C 매핑 버튼이 뜬다.
4. 수현님이 Speaker A/B/C를 실제 팀원으로 지정한다.
5. 매핑된 팀원에게 DM으로 회의 후 중요하다고 보는 일을 입력하라는 요청이 간다.
6. 각 팀원은 DM 버튼을 눌러 다음 내용을 적는다.
   - 내가 먼저 해야 할 일
   - 남이 맡아야 한다고 보는 일
   - 중요하다고 보는 순서
   - 안 해도 된다고 보는 후보
7. 모든 답변이 모이면 Subjector가 회의 전사와 팀원 의견을 함께 보고 task 후보를 만든다.
8. 각 담당자는 자기 DM에서 후보를 `채택`, `제외`, `수정` 중 하나로 처리한다.
9. `채택` 또는 `수정해서 반영`된 후보만 실제 task로 저장된다.
10. 각 담당자는 Subjector Bot DM에 `최신화`를 보내 #in-process 보드를 갱신한다.

## 테스트용 강제 진행

테스트 중 다른 팀원의 답변을 받을 수 없을 때만 사용한다.

Render 환경변수에 아래 값을 넣고 배포하면 켜진다.

```env
ENABLE_TEST_PARTICIPANT_SKIP=true
```

수현님이 먼저 의견을 입력한 뒤 아직 답변 대기자가 있으면, 수현님 DM에 `테스트용: 현재 답변만으로 진행` 버튼이 뜬다. 이 버튼을 누르면 현재 저장된 답변만으로 task 후보를 생성한다.

실제 운영에서는 이 환경변수를 끄거나 삭제하고, 모든 참여자 답변을 받은 뒤 진행하는 것을 권장한다.

## #in-process에서 task 진행하기

1. Subjector Bot DM에 `출근` 또는 `최신화`를 보낸다.
2. `#in-process`에서 내 task 보드를 확인한다.
3. 새 task를 시작할 때 `수락 및 Codex 프롬프트 생성`을 누른다.
4. `Codex 프롬프트 복사`로 프롬프트를 복사해 Codex에 붙여넣고 작업한다.
5. 작업 중 중요한 변경이 생기면 `변경 요청`을 누르고 Codex가 만든 초안을 붙여넣는다.
6. 작업을 끝냈으면 `완료`를 누르고 Codex 완료 결과를 붙여넣는다.
7. 오늘 끝내지 못하면 `오늘은 여기까지`를 누르고 Codex 진행 상태를 붙여넣는다.

## 완료 검수

- `완료` 제출은 LLM이 수행 적절성을 검수한다.
- 충분하면 task 상태가 `완료`가 된다.
- 부족하면 `보완 필요`로 남고, 피드백은 스레드에 남는다.
- 검수 provider는 Render 환경변수로 OpenAI/Gemini 중 선택할 수 있다.

## 퇴근과 오늘 요약

1. 퇴근 전 Subjector Bot DM에 `퇴근`을 보낸다.
2. Subjector가 오늘 한 일 요약을 DM으로 보낸다.
3. 완료, 오늘은 여기까지, 변경 요청, 미정리 상태를 task별로 정리한다.

## #finals 누적 정리

1. 모든 사람이 퇴근하면 수현님 DM에 #finals 미리보기가 생성될 수 있다.
2. 또는 수현님이 Subjector Bot DM에 `finals 업데이트`를 보낼 수 있다.
3. 미리보기를 확인한 뒤 `승인하고 반영하기`를 누르면 `#finals`가 업데이트된다.
4. 최종 요약은 최신 상태로 다시 작성되지만, 변경/충돌 이력은 남긴다.

## Render 배포 확인

- GitHub main에 push하면 Render가 자동 배포한다.
- Slack에서 바뀐 기능이 안 보이면 Render에서 `Deploy latest commit`을 누른다.
- 상태 확인은 `https://subjector.onrender.com/health`에서 PIN 입력 후 확인한다.

## 현재 남은 작업

- `#회의-결과록`에 짧게 적은 생자 텍스트 변경사항을 task에 반영하는 흐름
- 오늘 테스트에서 발견한 수정사항 반영
